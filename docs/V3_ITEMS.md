用户在 2026-11-10 的几轮讨论里定下方向，最后一句是“都按你建议来实现”。只给新开的局（`rules.items: 1`），以前开的局照旧。数字都是第一版，平衡模拟（§7）以后再调。

## 1. 格子

普通卡（第一张和大多数长出来的卡）在原来的配比上加：

| 格子 | 5×5 | 6×6 | 7×7 | 挖到 |
|---|---|---|---|---|
| 煤炭 `coal` | 2 | 3 | 4 | 煤炭 +1（满了不算） |
| 木棍 `stick` | 2 | 3 | 4 | 木棍 +1（满了不算） |
| 藏宝图 `map` | 0–1 | 0–1 | 1 | 藏宝图 +1 |
| 急迫药水 `potion` | 0–1 | 0–1 | 0–1 | 只在挖掘间隔 ≥3 秒的局里有 |
| 试炼钥匙 `key` | 30% 有 1 把 | 同 | 同 | 钥匙 +1 |

望远镜少一点：6×6 两个、7×7 两个（5×5 还是一个）。剩下的格子是绿宝石。

区块卡的新格子：

| 格子 | 在哪 | 挖到 |
|---|---|---|
| 宝库 `vault` | 试炼密室，固定位置，不能挖 | 拿钥匙点它开一次（§3） |
| 装饰 `deco` | 试炼密室（凝灰岩砖、铜灯），废弃矿井（铁轨） | 不能挖，不算进“已挖” |
| 岩浆 `lava` | 下界，开局 2 格，会流 | 不能挖 |
| 远古残骸 `debris` | 下界 1 格 | 10 份小奖；岩浆吞不掉 |
| 蜘蛛网 `cobweb` | 废弃矿井 3 格 | 下一次挖要多等 5 秒 |
| 刷怪笼 `spawner` | 废弃矿井 1 格 | 中毒 3 次（§3） |
| 箱子矿车 `minecart` | 废弃矿井 2 格 | 50% 2–4 份小奖，25% 一个火把，25% 一张藏宝图 |
| 末影箱 `ender` | 末地宝藏，60% 有 1 个 | 末影箱 +1 |

“危险”指会扣分的格子：TNT、末影水晶、刷怪笼。

## 2. 区块

从第 2 张普通卡起，每张长出来的卡按种子抽：普通 55%，试炼密室 12%，废弃矿井 12%，下界 11%，深暗之域 10%。末地宝藏照旧由末影之眼开。

- **试炼密室**（7×7）：四角和正中是装饰；第 4 行第 2、6 格是宝库。其余 42 格：钻石 5、金苹果 1、双铁镐 2、TNT 按 6×6 的难度数、珍珠 1、盾牌 2、钥匙 2、煤炭 2、木棍 2、望远镜 1，剩下绿宝石。
- **废弃矿井**（6×6）：第 3 行中间 4 格是铁轨（装饰）。其余：蜘蛛网 3、刷怪笼 1、箱子矿车 2、煤炭 4、木棍 4、TNT 按 5×5 的难度数、钻石 2、珍珠 1、双铁镐 1、盾牌 1，剩下绿宝石。
- **下界**（6×6）：岩浆 2（开局就看得见）、远古残骸 1、钻石 4、TNT 按 6×6、金苹果 1、珍珠 1、双铁镐 2、盾牌 2，剩下绿宝石。这张卡上每挖 3 格，岩浆往旁边（上下左右）一格没挖开的格子流一格，挑哪格由种子定，远古残骸、末影珍珠、末影之眼不会被吞；旁边只剩这几样时，岩浆从这张卡别处冒出来（不然“这次没流”就泄露了旁边是大奖）。被吞的格子翻开给大家看（“一颗钻石掉进了岩浆”），然后就没了。红包里的钱不放在格子里，所以这格本来要付的钱还在红包里，留给别的格子。
- **深暗之域**（7×7）：钻石 8、金苹果 2、双铁镐 2、TNT 按 7×7、珍珠 2、盾牌 2、望远镜 1，剩下绿宝石。卡上有“噪音”，每挖一格加一，大家看得见；到了一个不公开的数（种子定，在格子数的 45%–75% 之间）就唤醒监守者：挖响最后一下的人手上扣一半（盾牌挡不住，末影箱里的不算），这张卡关闭，剩下的格子不能再挖。
- **地图不会长不动**：还能挖的卡上一颗没挖的末影珍珠都不剩时（监守者关卡、岩浆都可能造成），在刚挖的那张卡旁边长一张新卡。2026-11-11 的模拟里，没有这一条时人多的局有一成停住，后来的人一分都拿不到。

## 3. 道具

被动的自动生效；主动的放在工具条里，自己决定什么时候用。用道具不花镐子的机会。

| 道具 | 种类 | 从哪来 | 做什么 |
|---|---|---|---|
| 盾牌 | 被动，最多 3 面 | 格子 | 自动挡一次 TNT 或末影水晶，满了再挖到转成一份小奖 |
| 煤炭、木棍 | 被动，各 2 格进度 | 格子 | 两样都满，自动做成 1 个火把，两样清零；满了再挖到不算 |
| 中毒 | 被动，3 次 | 刷怪笼 | 之后每挖一次（附魔镐一次也算一次），扣手上 5%，盾牌挡不住；再挖到刷怪笼重新算 3 次 |
| 望远镜 | 对一格 | 格子 | 看一格是什么，只有自己看得见 |
| 火把 | 对一个角 | 合成、箱子矿车 | 插在卡内部四格相交的地方，大家都看得见；颜色说这 4 格里还没挖开的危险有几个：绿 0、黄 1–2、红 3–4。4 格都挖开（或被岩浆吞掉）就灭。一个角一个 |
| 附魔镐（横三格、竖三格、十字） | 对一片 | 附魔台 | 一次挖开形状里没挖开的格子，每格照常算（奖励、TNT 各算各的，盾牌一格挡一次），按从上到下、从左到右；框里挖过的跳过，至少要有一格能挖。各记次数，用它不花镐子的机会，但要等挖掘间隔 |
| 附魔台 | 弹窗 | 宝库 | 随机给两种形状（种子定，换不了），挑一种，得到这种附魔镐 2 次 |
| 末影箱 | 弹窗 | 末地宝藏 | 手上的分一半存进箱子、一半毁掉（留在红包里），手上从 0 开始。箱子里的 TNT、末影水晶、苦力怕、监守者都扣不到，金苹果也不翻它；领取时一起算。一个只能用一次 |
| 急迫药水 | 确认 | 格子 | 10 秒里挖掘间隔变成 1 秒 |
| 藏宝图 | 确认 | 格子、箱子矿车 | 先抽种类，奖励越大越难抽中（按价值的倒数：绿宝石 1、金苹果 3、钻石 5、远古残骸 10），再从所有没挖完的卡里挑一格这种、自己还不知道的；只有自己看得见，镜头飞过去 |
| 试炼钥匙 | 对宝库 | 格子 | 开一次宝库：每个宝库总共能开 4 次（上面写着还剩几次），每人每个宝库一次。开出：45% 三份小奖，25% 一颗钻石（5 份），20% 附魔台，10% 盾牌（满了换一份小奖） |

**机会和领取**：镐子的机会和所有附魔镐的次数都用完，才自动领取。领取的分 = 手上 + 末影箱。

**苦力怕**（防蹲守）：新参数 `creeper`（秒，默认 60，0 是不开，至少是挖掘间隔的两倍）。手上有分、开着网页、这么久没挖也没用道具，苦力怕从屏幕边上探头，10 秒倒数；这 10 秒里挖一格、用道具或领取，它就走开；不然炸掉手上的 20%。网页打开时、每次挖和用道具都重新计时。网页到点时发 `POST /creeper`，服务器核对时间（留 2 秒余量）再扣。

## 4. 接口

`POST /v3/api/use`，身体 `{ item, cardId?, index?, choice? }`：

| item | 要带 | 说明 |
|---|---|---|
| `spyglass` | cardId, index | 同以前 |
| `torch` | cardId, index | index 是那个角右下的格子（行、列都 ≥1） |
| `pick-h` `pick-v` `pick-x` | cardId, index | index 是形状的中心；出界的格子不算 |
| `table` | choice: `h`/`v`/`x` | 必须是给出的两种之一 |
| `ender`、`potion`、`map` | — | |
| `key` | cardId, index | index 是宝库 |

回答：`{ ok, me, blocked, text, ... }`。附魔镐挖格子时每格一条第 2 版推送（序号连着），回答里带 `updates`。火把、宝库变了推一条 `{ type: "card", card }`（不带序号，网页直接换掉那张卡）。藏宝图回答带 `{ cardId, index, kind }`。

`POST /v3/api/creeper`：身体 `{}`，回答 `{ ok, me, lost }`。

**公开的卡**（`publicCard`）多出：`kind`（`trial`/`mine`/`nether`/`deep`/`end`）、`fixed`（`{ 格号: "deco"|"vault"|"lava" }`）、`vaults`（`{ 格号: 还能开几次 }`）、`torches`（`[{ at, level, name }]`，只给亮着的）、`noise`、`closed`。被岩浆吞的格子在 `cells` 里是 `{ kind, uid: 0, name: "", at, burn: 1 }`。

**第 2 版推送**（`type: "cell"`）多出：`torches`（这张卡有火把时）、`burned`（`[{ index, kind }]`）、`noise`、`closed`。

**自己的**（`privatePlayer`）多出：`items`：`{ torch, map, potion, ender, table, key, pick: { h, v, x } }`，`coal`、`stick`、`poison`、`chest`、`hasteMs`、`slowMs`、`tableChoices`（手里有附魔台时，下一个附魔台的两种）、`creeperMs`（还有多少毫秒苦力怕来，不适用时 null）、`vaultsOpened`（`["卡号:格号"]`）。

## 5. 网页

- **工具条**：像右下角的缩放一样浮在地图上，只有自己那一块（2026-11-11 用户：不要一整行的底）：竖着的画面在左下，横着的在左边居中；挖卡时镜头让开它那一条。镐子固定在最前面；放不下时左右滑（横屏上下），两头渐隐，有箭头；电脑上滚轮、拖动也能滚。道具出现时长出来带一道扫光，用完收起来，数字变化跳一下，附魔镐一直有附魔光。煤炭、木棍是进度条，合成时两样飞到一起变成火把飞进火把那一格。中毒格是刷怪笼，里面蜘蛛在转，冒绿色粒子，右下角绿字写还剩几次。
- **一套点法**：见 `docs/ITEM_UX.md`（道具交互规范：五类道具、工具条 / 弹窗 / 顶上一行三块界面、每类的流程、用词、新道具清单）。现在做成的：点工具条上的一格都是弹窗；瞄准类（附魔镐、望远镜、火把、钥匙）先弹引导（不再提示 / 取消 / 使用，选了“不再提示”这台设备以后直接开始），进入选位置以后顶上一直有步骤条（这一下会怎样、问号再看引导、取消）；即用类（药水、藏宝图）确认弹窗；抉择类（末影箱、附魔台）专属弹窗；被动类和镐子说明弹窗。
- **顶上一行**：一次一条，苦力怕 > 步骤条 > 通知（末影箱存好了）。电脑上跟着指针的小提示只在不选位置时出（火把颜色、宝库还能开几次、冷却）。
- **指针**：像素箭头加道具小图标，箭头尖是点的位置；冷却时图标变灰，附魔镐带紫光。
- **弹窗**：工具条上点开的道具、末影箱、附魔台、宝库开出的东西。
- **顶栏**：大数字是手上；末影箱里有分时，右上角一个绿色的 +x。存进去时地图顶上出一句说明，点“知道了”收起，点绿字能再看。
- **苦力怕**：从地图右边探头，“嘶……”，最后几秒胀大闪白，炸时白闪、震动。

## 7. 平衡

2026-11-11 的模拟（`game/scripts/sim-items.mjs`，每种难度 60 局，每人把机会挖完）：新配比每次机会平均发出去的是旧局的 0.75（简单）、0.67（普通）、0.43（困难），新局的绿宝石按这个比例变贵（`ITEMS_UNITS`）。这样按预计人数开的红包，新局和旧局一样几乎都能发完；模拟里的人攒到 4–40 份小奖就领时，新局发出 95%–100%，旧局 99%–100%；一分没拿到的人在 2% 以内。人和人的差距比旧局大一点（20 人时最多的是中位数的 2.5 倍，旧局 2.2 倍），这是道具和区块带来的波动。

绿宝石值多少照旧按“每挖一格平均几份小奖”算，新局的配比少了绿宝石、多了道具和垃圾，平均值要按新配比重算；区块卡、宝库、箱子矿车、附魔镐多挖的格子靠模拟估。`game/scripts/sim-items.mjs` 用种子跑整局，看发出去的钱占奖池多少、人和人差多少，再调这一页的数。
